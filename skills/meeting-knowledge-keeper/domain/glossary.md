# Glossary

用于沉淀整个 vault 共用的术语。这里的内容不是单场会议事实，而是帮助 agent 正确理解会议文本的背景词典。

## 使用规则

- 只放团队长期复用的术语。
- 不确定的解释标 `status: tentative`，不要写成确定知识。
- 单个项目才使用的缩写，优先放到项目级 `knowledge/domain-context.md` 或 `knowledge/entity-aliases.md`。
- 不要用术语表替代会议来源；正式结论仍必须链接到会议或 artifact。
