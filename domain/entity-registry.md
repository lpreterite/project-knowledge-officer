# Entity Registry

用于沉淀整个 vault 共用的人、组织、产品、系统、平台和缩写别名。目的是让 agent 在会议里遇到简称、口语名、英文名时能正确归一。

## 使用规则

- 只放跨项目复用或全团队共用的实体。
- 单项目实体优先放到项目级 `knowledge/entity-aliases.md`。
- 不确定映射标 `status: tentative`。
- 涉及敏感身份、账号、联系方式时，不要写入不必要细节。
