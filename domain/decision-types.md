# Decision Types

用于定义团队常见决定类型。分析会议时，如果某条决定属于这些类型，可以在描述或备注中标出，便于后续检索。

## 决定类型

| Type | 说明 | 常见证据 |
| --- | --- | --- |
| `scope` | 项目范围、边界、排除项、阶段划分。 | 明确说“先做 / 暂不做 / 不包含”。 |
| `priority` | 优先级、先后顺序、资源倾斜。 | 明确说“优先 / 下一步 / 第一阶段”。 |
| `solution` | 业务方案、产品方案、技术路线。 | 对比多个方案后选定一个方向。 |
| `commercial` | 报价、采购、合同、费用、商务口径。 | 金额、人天、采购流程、报价边界。 |
| `delivery` | 排期、里程碑、验收、上线、培训。 | 日期、交付物、验收方式、owner。 |
| `governance` | 权限、流程、质量、安全、协作机制。 | 审批、权限、审计、SOP、版本管理。 |

## 使用规则

- 决定类型是辅助标签，不替代 `Domain`。
- 不确定时可以不标，或写入 open question。
- 只有明确同意、安排或执行的内容才进入 decisions。
