# Writing Style

用于定义整个 vault 的写作风格，保证不同 agent 或不同时间维护出来的纪要一致。

## 默认风格

- 默认使用中文。
- 保留必要英文术语、产品名、系统名、字段名、命令和路径。
- 用短句，优先写清楚事实、决定、todo、风险。
- 不写营销化、修辞化、主观夸张的表达。
- 不把推测写成事实。
- 不把“有人提到 / 可以考虑 / 可能要”写成决定。

## 术语处理

- 首次出现缩写时，如果术语表已有解释，可直接使用。
- 如果术语表没有解释，但会议语境足够明确，可以在 `analysis.md` 中写“按本次会议语境理解为……”，并建议补充术语表。
- 如果术语含义不确定，进入 open question。

## 来源表达

推荐写法：

- “来源：`transcript.md`，发言人提到……”
- “来源：`artifacts/<file>` 第 N 页……”
- “用户补充：`artifacts/<note>.md`……”

避免写法：

- “显然……”
- “应该是……”
- “大概率……”
- “行业通常……”但没有来源或说明。
